## Ringkasan

1. Instal Git dari git-scm.com, lalu cek dengan `git --version`.
2. Buat SSH key di komputer lokal.
3. Tambahkan SSH key ke akun GitHub (Settings > SSH and GPG keys).
4. Tes koneksi dari lokal ke GitHub.
