Studi kasus: kelas `Mahasiswa` yang menyimpan NIM, nama, dan nilai (tugas, UTS, UAS).

## Isi folder

| Folder | Berkas | Keterangan |
|---|---|---|
| `java/` | `Mahasiswa.java`, `Main.java` | Versi Java |
| `php/` | `Mahasiswa.php`, `main.php` | Versi PHP |

## Aturan yang dijaga (enkapsulasi)

- NIM tidak boleh kosong dan tidak bisa diubah setelah dibuat.
- Setiap nilai harus di rentang 0 sampai 100.
- Nilai akhir = 30% tugas + 30% UTS + 40% UAS.
- Huruf mutu: A (>= 80), B (>= 70), C (>= 60), D (>= 50), selain itu E.

## Cara menjalankan

Java:
```bash
cd java
javac *.java
java Main
```

PHP:
```bash
cd php
php main.php
```
