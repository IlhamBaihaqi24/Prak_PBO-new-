## Isi folder

| Folder | Berkas | Keterangan |
|---|---|---|
| `java/` | `RekeningBank.java`, `Main.java` | Versi Java |
| `php/` | `RekeningBank.php`, `main.php` | Versi PHP |

## Konsep yang dipelajari

- Constructor lebih dari satu (Java) dan default parameter (PHP).
- Anggota `static`, misalnya penghitung jumlah rekening.
- Konstanta untuk bunga tahunan, biaya administrasi, dan batas penarikan.
- Validasi: saldo tidak boleh negatif, setoran dan penarikan harus positif.

## Cara menjalankan

Java:
```bash
cd java
javac *.java
java Main
```

PHP:
```bash
cd php
php main.php
```
